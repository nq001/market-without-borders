# Frontend Implementation Phases

This directory contains the implementation stages for the **React 19 + TypeScript + Vite + TailwindCSS** frontend layer of the Market Without Borders (MWB) platform.

---

## Phase Index

| Phase | Specification Document | Description |
| :--- | :--- | :--- |
| **01** | [`01-admin-console.md`](./01-admin-console.md) | Super Admin 14-section governance console across Overview, Management, Moderation, Business, and System. |
| **02** | [`02-owner-workspace.md`](./02-owner-workspace.md) | Store Owner / Staff 11-section operational workspace with staff RBAC and earnings breakdowns. |
| **03** | [`03-customer-experience.md`](./03-customer-experience.md) | Storefronts, category showcase, shared multi-store cart, split checkout, wishlist, and about policies. |
| **04** | [`04-internationalization-rtl.md`](./04-internationalization-rtl.md) | English & Arabic bilingual translation dictionaries with dynamic Right-to-Left (`dir="rtl"`) layout switching. |
| **05** | [`05-frontend-testing-vitest.md`](./05-frontend-testing-vitest.md) | Unit and snapshot testing via Vitest covering minor-unit currency formatting and UI components. |
| **06** | [`06-production-build-vite.md`](./06-production-build-vite.md) | Production build pipeline (`tsc && vite build`) with zero TypeScript errors and code chunking. |
